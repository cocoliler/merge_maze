## 2026-11-18（深夜2）冰塔特效配色加深

**问题**：碎冰（`fx_ice`）和冰雾（`fx_frost_fog`）的素材都接近纯白，在浅灰路面 / 白色敌人身上
白对白，几乎看不出特效开了没有。

**改动**

- `scripts/Fx.gd`：`burst_seq()` 新增 `albedo_tint`（默认 `Color.WHITE`，不影响炮塔爆炸），
  乘到贴图本身而不是只加自发光 —— 素材偏白的特效才有办法压出颜色。
- `scripts/Tower.gd`：碎冰改用 `albedo_tint = Color(0.55, 0.86, 1.0)`，从白色块变成明显的冰蓝块；
  尺寸 1.8 → **3.4**、时长 0.30 → **0.45**，并额外叠一颗近白闪光（`Fx.flash`）当亮芯。
  位置从「敌人位置 + 0.45」改成「**+0.85 并沿视线往镜头推 0.55**」（`_cam_dir()`）。

**为什么之前「看不到」**（和泥潭那次同一类坑，但不是同一个原因）

- 不是被地图盖住：碎冰是**竖直 billboard**（挂在敌人胸口），和泥潭那种贴地 decal 完全不同；
  地面层（草地 0.8 / 路面 0.86 / 桥顶 0.94）只影响贴地物体。
- 真正的原因是这个素材**内容全挤在画布下半部**：顶部第 2~6 行是一颗几像素的小冰晶，
  第 20~38 行才是冰渣堆。挂在 `敌人 y + 0.45` 时，画布下沿落在 **0.79**（比路面 0.86 还低），
  上半部的冰晶又只有几像素 —— 能看见的只剩「脚下一小撮白点 + 头顶一个点」。
- 现在整张素材（0.45 高的画布 → 3.4 尺寸约 1.3 高）整体抬到 1.0~2.3 之间，
  且被推到敌人身体前面，不再被自身模型遮挡。
- 顺带把冰雾的离地高度 0.15 → **0.20**（世界 1.0），保证在拱桥顶（0.94）之上，
  避免和泥潭一样被路面吃掉。
- `scripts/FrostFog.gd`：新增 `FOG_COLOR = Color(0.34, 0.60, 0.98)`（比塔身光环深一档的蓝）；
  三层透明度 0.46/0.30/0.18 → **0.62/0.44/0.26**；自发光 0.22 → **0.08**
  （unshaded 下 emission 就是往上加亮度，加多了雾会重新发白）；圆盘边缘 alpha 曲线
  `[1.0, 0.88, 0.42, 0]` → `[1.0, 0.94, 0.66, 0]`，雾不再只浓在中间一小圈。
- `scripts/Tower.gd`：冰雾底色用 `FrostFog.FOG_COLOR` 掺 30% 变异色，而不是直接用偏白的变异 `tint`。

**想再浓/再淡就调这几个数**：`FrostFog.LAYERS` 的透明度列、`RING_ALPHA` 曲线、`FOG_COLOR`。

## 2026-11-18（深夜）变异「霜环」改成不攻击的冰雾光环塔

**动机**：霜环原来的定位是「减速 +14%，溅射范围 +1.0」，本质还是「冰塔加强版」——
和另外两条路线（碎冰打伤害、寒潮打射程）在同一条赛道上比数值。
改成一个**纯辅助光环**：放弃全部输出，把射程圈铺满冰雾，圈内敌人恒定减速 50%。
这样玩家要做的是「把路卡进雾里」而不是「再多一座 DPS 塔」，选择才有取向差异。

**改动**

| 位置 | 内容 |
| --- | --- |
| `scripts/FrostFog.gd`（新增） | 冰雾表现层：三层同心圆盘（主雾体 / 细节 / 高光丝）平铺在地面上，反向缓慢自转 + 呼吸；形状用**网格顶点 alpha**（`vertex_color_use_as_albedo`）烘成「中心浓、边缘淡」，贴图 UV 缩放到铺满整圈 |
| `textures/fx_frost_fog.png`（新增） | 冰雾贴图：从参考图裁出、抠掉棋盘格背景（亮度取 alpha + 反预乘），按 alpha 重心裁成 256×256 正方形、雾团居中、四周透明 |
| `data/TowerData.gd` | 霜环：`mods` 改为 `{"dmg_mul": 0.0, "slow_set": 0.50}` + 顶层 `"aura": true`；`desc` 重写。`slow_set` 是新增的 mods 字段（把减速定死，不叠基础塔的 0.22） |
| `scripts/Tower.gd` | 新增 `is_aura()` / `_update_aura()` / `_rebuild_fog()`：`_process` 里光环塔走最前面那条分支（既不射线也不打子弹）；每次重建塔身按当前 `range_v` 重铺冰雾；被压制时雾熄灭；`info_text()` 对光环塔显示「射程内减速 50% · 不造成伤害」 |
| `scripts/TextureLib.gd` | 槽位表加入 `fx_frost_fog` |
| `README.md` | 变异章节补「霜环 = 光环塔」，`mods` 字段表补 `slow_set` / `aura` |

**设计要点**

- **真的没有伤害**：`dmg_mul: 0.0` 让 `damage` 归零，且 `_update_aura()` 只调 `apply_slow()`，
  不碰 `take_damage()`，也不走 `Bullet.apply_on_hit_status()`（毒 / 流血 / 破甲属于「弹药词条」，
  不打伤害的塔不该触发）。射线节点会被 `_beam.stop()` 彻底关掉，不会留一条残线。
- **为什么雾是圆盘 + 顶点 alpha**：一张方片贴图铺开会把四个角捅到射程圈外；要在
  `StandardMaterial3D` 里做径向遮罩只能上自定义 shader。这里把同心环的 alpha 直接烘进网格
  （1.0 → 0.88 → 0.42 → 0），配合 UV 缩放把贴图拉到满圈，就得到「整圈是雾、边缘自然淡出」，
  既不写出圈也不出现硬切边，还省了一个 shader。
- **半径跟着射程走**：雾节点整体 `scale = range_v`，并在 `_build_body()` 里重建，
  所以升级、寒潮（射程 +25%）、卡牌射程加成之后雾圈和射程圈仍然严丝合缝。
- **压制联动**：被大首领脉冲压制时冰雾 `visible = false`，玩家能直接看出这座塔暂时失效。
- **成本**：每座霜环塔常驻 3 个 MeshInstance3D + 1 份共享网格，减速每 0.2 秒刷一次，
  比让它每 0.95 秒生成一颗子弹更省。

**怎么自测**

1. 冰塔升到 Lv.3 → 选「霜环」：塔身停止射击，射程圈内立刻铺满淡蓝冰雾（雾会缓慢翻涌）。
2. 敌人走进雾圈：立刻进入减速状态（身上变蓝、移动明显变慢），并且**不掉血**、不出现伤害数字。
3. 给塔喂射程（寒潮 / 射程卡）后升级：雾圈和射程圈应同步变大，不会出现「雾比圈小」。
4. 卖塔 / 重开：雾节点随塔一起销毁，不留残影。

## 2026-11-18（晚）冰塔改为「持续冰冻射线」

**动机**：冰塔原来是「射一发冰弹 → 命中一次 → 结算一次伤害」，和箭塔 / 炮塔是同一套手感，
只在附带减速上有所区别。参考 Kingdom Rush 里工程师 / 冰系塔的攻击表现（那道扭动的青白能量束，
末端在敌人身上炸开），把冰塔改成**锁定敌人一直照射**的射线塔：冻住谁、冻了多久，一眼就看得到。

**改动**

| 位置 | 内容 |
| --- | --- |
| `scripts/IceBeam.gd`（新增） | 射线表现层：`ImmediateMesh` 画两条正对镜头的三角带（外圈青蓝光晕 + 内圈近白核心，ADD 叠加），路径上叠正弦扰动；命中点 / 塔口各挂一团程序化径向光斑（`GradientTexture2D` 径向渐变，无需外部贴图）。起手 0.15 秒渐亮，不闪 |
| `scripts/Tower.gd` | 新增 `is_beam()` / `shot_interval()` / `_update_beam()` / `_beam_apply()` / `_in_range()` / `_sync_beam_look()`；`_process` 里射线塔走独立分支（不生成 `Bullet`，`_beam_tick` 等价于原来的 `cooldown`），暂停 / 被首领压制时自动断线；`_build_base()` 挂 `IceBeam`，`_build_body()` 按等级 / 变异同步粗细与颜色 |
| `scripts/Bullet.gd` | 把「减速 + 毒 / 流血 / 破甲 / 易伤」抽成 `static apply_on_hit_status()`，子弹和射线共用一份实现 |
| `scripts/Fx.gd` | `burst_seq()` 增加可选 `tint` 参数：炮塔爆炸仍是暖橙，碎冰走冷蓝，不会被自发光染成橙色 |
| `textures/fx_ice_0.png` / `fx_ice_1.png`（新增） | 射线命中时的碎冰序列帧：从参考图 `go_towers_engineer_kr1-1.png` 裁出两组，抠掉棋盘格背景（按亮度取 alpha + 反预乘），58×40 带透明通道，共 2 帧 |
| `scripts/Tower.gd` `_beam_apply()` | 每次结算伤害时在主目标身上放一团碎冰（`Fx.burst_seq("fx_ice", …)`）；没放贴图就回退成冰蓝闪光 + 冲击环 |
| `scripts/TextureLib.gd` | 槽位表加入 `fx_ice_0` / `fx_ice_1`，开局「还缺哪些图」的报告里能看到 |
| `data/TowerData.gd` | 冰塔加 `"beam": true`，`desc` 改写（伤害与射速的数值一个都没动） |
| `README.md` | 塔数值基线、减速说明补上「冰塔是射线塔」的口径 |

**设计要点**

- **只换表现，不换数值**：伤害节奏还是原来的「每 `1/攻速` 打一发满额 `damage`」。
  最初试过摊成「每秒伤害 = `dmg × rate`」的连续掉血，但手感和面板都对不上（射速这一栏会失去意义），
  所以最终保留原攻速与原单发伤害，只是**省掉了子弹飞行的那 0.3 秒**：锁上就打，射线一直连着。
- **`_beam_tick` 就是 `cooldown`**：累加到 `shot_interval()` 就打出一发，然后用减法扣掉间隔
  （不是清零），掉帧时长期射速不会漂。
- **溅射 / 暴击 / 附带状态全走原规则**：主目标吃满、圈内其他敌人吃 `SPLASH_DMG_COEF` 衰减；
  暴击每次独立 roll；减速与毒 / 流血 / 破甲 / 易伤由 `Bullet.apply_on_hit_status()` 统一处理。
- **换目标**：目标死亡（含 `hp <= 0`）/ 走出射程 / 隐身时自动重挑（口径与 `_find_target` 相同，
  所以「目标优先级 Q」对射线塔同样有效），重挑节流仍是 `AIM_REFRESH`。
- **命中特效只在主目标身上**：溅射圈里的其他人不额外放碎冰，否则一次开火能同时炸出 5 团冰花，
  比伤害数字还乱。特效时长 0.3 秒、按 `1/攻速`（约 0.95 秒）的节奏重复，看起来就是「射线一直
  在敌人身上结霜」。
- **参考图是棋盘格预览图**：直接当贴图用会把深灰格子也带进来，所以先按亮度取 alpha，再用
  反预乘把背景色从半透明边缘里减掉（否则边缘会带一圈灰边）。
- **不新增节点**：射线是一个 `ImmediateMesh` + 两个 billboard 光斑，每帧重画顶点；
  每座冰塔常驻 3 个节点，比「每次开火生成一颗子弹」更省。

**怎么自测**

1. 第 3 波后建一座冰塔，敌人进入射程：塔顶冰晶到敌人之间会出现一条扭动的青白射线，
   命中点有一团脉动的冰爆光斑；伤害数字与掉血节奏应和改造前一致（Lv.1 约每 0.95 秒跳一次 9）。
2. 每次结算伤害时，主目标身上会炸开一小团碎冰（`fx_ice` 两帧，0.3 秒淡出），
   和射线一起看就是「冰束在敌人身上不断结霜」。
3. 敌人走出射程 / 被打死：射线立刻断开并自动挂到下一个目标。
4. 敌人身上应持续保持冰蓝色（每次命中都在刷新减速）；喷火塔打它时仍然吃「冰火两重天」加成。
5. 满级选变异：射线的光晕颜色会变成变异色（霜环淡蓝 / 碎冰亮白 / 寒潮深蓝），Lv.3 也更粗。

## 2026-11-18（下午）变异「双管齐射」的专属炮塔模型

**动机**：三条炮塔变异里，攻城巨炮有 9 帧爆炸、震地雷有泥潭，唯独「双管齐射」满级后还是单根粗炮管
——玩家只能靠脚下光环的颜色分辨自己选了哪条路，模型层面没有任何「变成弹幕塔」的信息。

**改动**

| 位置 | 内容 |
| --- | --- |
| `tools/gen_tower_models.py` | `build_cannon(level, twin=False)` 增加双管分支，配套 `twin_barrels()`；`main()` 额外产出 `tower_cannon_l3_twin.glb`（第 22 个塔模型） |
| `scripts/Tower.gd` | 新增 `_custom_model_path()` / `mutation_short()`：先找 `tower_<kind>_l<等级>_<变异短名>.glb`，找不到回退普通模型 |
| `tools/gen_preview_scene.py` | `_TowerPreview.tscn` 的模型列表加入 `tower_cannon_l3_twin`，方便和单管版并排比对 |

**设计要点**

- 双管是「一体」的：两根细管嵌在同一个木炮座上，中间一根铁轴套、后面一个共用后座，
  再挂一个弹药箱；换弹时两管同时后坐，不会出现两根管子各自摇摆的割裂感。
- 管径 `r × 0.58`、管长 `ln × 0.80`，保留原来那套「两道铁箍 + 铜制喇叭口 + 内壁黑洞」的细节，
  只是缩小并排成一对 —— 远看仍是同一族造型。
- 模型里依旧只有 `Body` + `Turret` 两个节点，`Turret` 包住整个双管组件，
  所以 `Tower` 的转向逻辑一行都不用改：转的是炮座，两管天然同向。

**命名约定（以后加别的变异模型照这个来）**

```
models/towers/tower_<kind>_l<1..3>.glb          普通塔
models/towers/tower_<kind>_l<3>_<变异短名>.glb   变异专属（短名 = 变异 id 的最后一段）
```

`cannon_twin` → `tower_cannon_l3_twin.glb`；同理 `cannon_heavy` 想要专属模型就是
`tower_cannon_l3_heavy.glb`，`cannon_quake` → `tower_cannon_l3_quake.glb`。删掉文件即回退。

**怎么自测**

1. 跑一次 `python tools/gen_tower_models.py`，日志最后应出现 `tower_cannon_l3_twin.glb ... 双管炮塔 3`。
2. 切回 Godot 编辑器让它导入新 GLB（或命令行 `--import`），`models/towers/` 下会多一个 `.import`。
3. 满级炮塔选「双管齐射」：塔顶应变成一对细炮管（带弹药箱），攻击时两管一起转向目标；
   未变异的满级炮塔仍是单根粗管。

## 2026-11-18 炮塔特效分级 · 攻城巨炮序列帧 · 震地雷泥潭

### 1. 炮塔命中特效按等级分级

**动机**：一级炮塔的爆炸太小、看不清落点，满级炮塔打出来的和一级一模一样，没有成长感。

**改动**

| 等级 | 贴图槽位 | 说明 |
| --- | --- | --- |
| Lv.1 | `fx_explosion` | 原来的「烟 + 火花」小爆炸 |
| Lv.2 / Lv.3 | `fx_explosion_l2` | 新素材，碎石 + 浓烟，更炸 |

- `Bullet` 新增 `src_level`，`configure()` 末尾多了 `lvl` 参数；`Tower._shoot()` 把 `level` 传进来。
- 判定只有一个：`src_level >= 2`，所以**三级炮塔天然沿用了二级的特效**，不需要再单独写分支。
- 尺寸公式（`Bullet._spawn_flash`）：

```gdscript
var sz: float = 2.0 + splash * 0.55 + (0.6 if is_crit else 0.0)
```

  基础 2.0 + 溅射半径系数 0.55，暴击再 +0.6，播放时长 0.40s。
  （原来是 `1.25 + splash * 0.35`、0.34s —— 太小看不清落点，本轮整体放大了一档。）

- 回退链：`fx_explosion_l2` 缺图 → `fx_explosion` → 纯色光球。所以素材没凑齐也能跑。

**素材来源**：`extracted/textures/_assets/kr6-desktop/images/ipad/go_towers_catapult-1.png`（1228×1228 精灵图集）。
`fx_explosion_l2.png` 从 `(488, 470) - (596, 550)` 裁出，108×80。

### 2. 变异「攻城巨炮」改成 9 帧序列特效

**动机**：攻城巨炮（`cannon_heavy`）是「一炮清空半条路」的重击，单张图放大淡出撑不住这个份量。

**改动**

- 新增通用 API `Fx.burst_seq(parent, pos, prefix, count, size, duration, fade)`：
  一张 billboard 方片，按时间逐帧换 `albedo_texture`，整体放大到 1.25 倍，末尾淡出。
  **帧图必须同尺寸同画布**，否则切帧时会抖。

```gdscript
	# 逐帧切贴图（并行分支 + 延迟），播完再淡出，避免"啪"地消失
	var step := duration / float(frames.size())
	var tw := mi.create_tween()
	tw.set_parallel(true)
	tw.tween_property(mi, "scale", Vector3(1.25, 1.25, 1.25), duration)
	for i in frames.size():
		tw.tween_callback(_set_tex.bind(mat, frames[i])).set_delay(step * float(i))
	tw.tween_property(mat, "albedo_color:a", 0.0, fade).set_delay(maxf(duration - fade, 0.0))
	tw.chain().tween_callback(mi.queue_free)
```

- `Bullet._spawn_flash()` 里判断 `src_mutation == "cannon_heavy"`，用序列帧代替单图：

```gdscript
		if src_mutation == "cannon_heavy":
			# 攻城巨炮是「一炮清场」的重击，爆炸再放大 1.9 倍才压得住
			if Fx.burst_seq(get_parent(), pos, "fx_siege", 9, sz * 1.9, 0.62):
				return
```

  `1.9` 是调了两轮的尺寸系数（1.1 → 1.5 → 1.9）。攻城巨炮 splash = 1.6 + 1.2 = 2.8，
  实际炸开宽度约 3.7 世界单位（接近 2 格），暴击约 4.3。想再大就继续抬这个系数，
  超过 2.5 会盖住路面、看不清怪物走位。

### 3. 变异「震地雷」：从「命中减速」改成「炸出泥潭」

**旧行为**：`mods = { "splash_add": 1.8, "slow_add": 0.16 }` —— 命中谁就给谁挂 16% 减速，
和冰塔的减速走同一个字段，谁强听谁的，控制感和「地面变泥沼」的设定完全脱节。

**新行为**：

- `TowerData.MUTATIONS` 的 `cannon_quake` 只保留 `splash_add: 1.8`，描述改成
  「溅射范围 +1.8，命中处炸出泥潭 / 踏入泥潭的敌人减速 16%（持续 1.5 秒）」。
- 命中点生成一个 `MudPit`（新脚本 `scripts/MudPit.gd`），区域内的敌人才被减速。

**新常量（`data/TowerData.gd`）**

```gdscript
const MUD_RADIUS := 1.7              # 泥潭半径（世界单位，1 格 = 2.0）
const MUD_TIME := 1.5                # 泥潭存在时间（秒），到点自行干涸
const MUD_SLOW := 0.16               # 泥潭内的减速比例
```

**`MudPit.gd` 实现要点**

| 点 | 做法 |
| --- | --- |
| 形状 | `QuadMesh` 绕 X 轴转 -90° 平铺地面（不是 billboard），宽 = 2×半径，深按贴图宽高比压缩 |
| 序列帧 | `fx_mud_0…6` 共 7 帧，**在 `life` 秒内正好走完一遍，不循环**（`step = life / 帧数`），最后一帧停住淡出 |
| 生命期 | 1.5s，最后 0.3s 把 `albedo_color.a` 淡到 0 再 `queue_free` |
| 减速扫描 | 每 0.1s 遍历 `enemies` 组，**只算水平距离**（x/z），半径内调用 `apply_extra_slow(0.16, 0.3)`；落地当帧额外扫一次 |
| 离开泥潭 | 施加时只给 0.3s，走出后自然恢复，不会一出圈就瞬间复原 |
| 缺图回退 | 整组 `fx_mud_*` 缺失时退化成一个半透明泥色圆盘（`CylinderMesh`） |
| 数量 | 炮塔攻速不高（震地雷 0.48/s 左右），同一时刻场上通常只有 1~2 个，未做上限 |

**踩过的坑（重要）**

泥潭第一版高度是用「命中点 − 0.7 + 0.05」反推的，结果**大部分时候看不见**。
`GameGrid.gd` 里地面是分层的：

```gdscript
const SURFACE_Y := 0.8        # 草地顶面（塔 / 敌人 / 路面都从这层起）
const ROAD_Y := 0.06          # 路面相对 SURFACE_Y → 路面顶面 0.86
const BRIDGE_CROWN := 0.08    # 桥上路面再拱到 0.94
```

敌人恒在 `SURFACE_Y = 0.8` 上走，反推出来的泥潭落在 `0.85`，**比路面低 1cm，被埋进地下**；
偶尔命中点在路肩 / 草地上时才露出来 —— 表现就是「有时候没生成」。

现在统一写死地形高度，不再从命中点反推：

```gdscript
	mud.setup(Vector3(pos.x, GameGrid.SURFACE_Y + 0.16, pos.z))
```

比普通路面高 0.10、比桥拱顶高 0.02，和路面流动箭头（`GameGrid.FLOW_Y = 0.14`）同一量级。
**以后往地面贴任何东西，都用 `GameGrid.SURFACE_Y + 偏移`，不要用敌人坐标反推。**

**素材**：`go_towers_catapult-1.png` 图集 x≈137–156 那一列的前 7 帧（平静泥面 → 泥浆翻腾）。
统一到 **128×96** 画布、**底部对齐 + 水平居中**（泥坑贴地，飞溅向上长），导出 `textures/fx_mud_0.png … fx_mud_6.png`。

### 4. 减速改成「两层乘区」（Enemy）

**动机**：泥潭的 16% 必须是**额外**减速。原来 `apply_slow()` 是「取更强」：

```gdscript
slow_factor = maxf(minf(slow_factor, 1.0 - factor), 0.25)
```

冰塔 -22% 在场时，泥潭的 -16% 直接被吞掉，等于白做。

**新结构**

| 字段 | 来源 | 叠加方式 |
| --- | --- | --- |
| `slow_factor` + `slow_timer` | 冰塔等塔类减速 | 同一层内**取最强**（不叠加），受首领 `slow_cap` 限制 |
| `slow_extra` + `_slow_extra_timer` | 泥潭这类**地形减速** | 与上面**乘算**，独立计时 |

速度计算两处（地面行走 + 飞行怪）都改成：

```gdscript
var step := base_speed * slow_factor * slow_extra * (1.0 + _haste) * delta
```

新增方法：

```gdscript
## 地形减速（震地雷的泥潭）：**乘算**叠在冰塔减速之上，互不覆盖。
## 例：冰塔 -22%（slow_factor 0.78）+ 泥潭 -16%（slow_extra 0.84）→ 实际 0.655 倍速。
## 走的是独立乘区，所以不会被 apply_slow 的「取更强」逻辑吞掉。
func apply_extra_slow(factor: float, time: float) -> void:
	if _dying:
		return
	var f := clampf(factor, 0.0, 0.9)
	slow_extra = minf(slow_extra, 1.0 - f)
	_slow_extra_timer = maxf(_slow_extra_timer, time)
```

数值对照：

| 场景 | 实际速度倍率 |
| --- | --- |
| 只有泥潭 -16% | 0.84 |
| 只有冰塔 -22% | 0.78 |
| 冰塔 -22% + 泥潭 -16% | 0.78 × 0.84 = 0.655 |

**要注意的联动**：`is_chilled()` 只看 `slow_timer`（冰塔那层），所以**踩泥潭的敌人不算「被冻住」**，
不会被喷火塔误判成冰冻目标去触发「融化」加成。以后再加别的控制效果，沿用这个原则：
新效果单独开乘区 / 单独判定，别塞进 `slow_factor`。

**多个泥潭重叠**：`minf` 取最强的一层，不会叠成 0.84 × 0.84。想让泥潭互相叠加就把这行改成乘法。

### 5. 火电「超载」爆炸特效升级

`Bullet._shock_blast()` 原来只有纯色光球 + 圆环，和放大后的炮塔爆炸明显不在一个量级。

- 复用爆炸贴图 `Fx.burst(..., "fx_explosion", radius * 1.6 + (0.5 if is_crit else 0.0), 0.42)`
  （`SHOCK_BLAST_RADIUS = 2.2` → 约 3.5 单位宽）。
- 光球 / 圆环时长从 0.18 / 0.28 提到 0.22 / 0.34，与炮塔命中的 0.40 同一节奏。
- 伤害结算方式没动：仍然直接 `take_damage`，**不生成子弹**，避免连锁引爆无限递归。

### 7. 改完怎么自测

1. 起一局，建一座炮塔升到 Lv.2：命中爆炸应该是新图（碎石 + 浓烟）；Lv.1 仍是旧图。
2. 满级后选「攻城巨炮」：命中要放 9 帧序列，炸开约 2 格宽，`0.62s` 播完。
3. 满级后选「震地雷」：命中点必须**稳定**出现泥潭（重点看路面正中，别再被埋），
   1.5 秒内 7 帧走完一遍再淡出。
4. 同一只怪先被冰塔减速、再踩泥潭：速度应为「两个减速相乘」，肉眼比只有冰塔时更慢。
5. 踩泥潭的敌人被喷火塔打：**不应**出现白蓝色的「融化」蒸汽特效（泥潭 ≠ 冻住）。
